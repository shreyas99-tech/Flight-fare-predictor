🧠 How Machine Learning Understands Airline Pricing

01

Real Airline Yield Management

Airlines change prices based on seat scarcity and booking urgency. Our dataset (flights.csv) mimics 2,400 domestic Indian flights across busy routes like Delhi, Mumbai, and Bangalore.

02

Dense One-Hot Encoding

OneHotEncoder(sparse_output=False) converts text categories (airline, route, time of day) into dense binary arrays so the gradient boosting algorithm can process them at lightning speed.

03

HistGradientBoosting Trees

HistGradientBoostingRegressor is scikit-learn's modern boosting algorithm. It groups values into numerical bins and trains consecutive trees that iteratively correct past errors.

04

Instant Real-Time Valuation

The trained pipeline is frozen into flight_model.pkl. Flask serves the model, and asynchronous JavaScript displays the price without reloading the page.

Built strictly with Python, pandas, scikit-learn, joblib, Flask, HTML, CSS, and JavaScript.
